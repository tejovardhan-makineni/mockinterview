# Support and feedback

For setup help, search this repository's issues, then open a question describing
your OS, relevant versions, command, expected behavior and redacted error. For a
bug, include reproduction steps and whether it happened in hosted, local or demo
mode. Do not include a provider key, resume or full interview transcript.

For mockinterview.live account access, private data requests or Code of Conduct
reports, email the project maintainer at
[makinenitejovardhan@gmail.com](mailto:makinenitejovardhan@gmail.com). You do not
need to sign in. Include only the details needed to handle your request; never
send passwords, recovery links or API keys. For another installation, contact
its operator, who controls its accounts and data. Operators can set
`NEXT_PUBLIC_SUPPORT_EMAIL` when building the web app to show their own contact
on the Help & support page.

Use the in-product feedback controls to distinguish interviewer behavior from
product problems. A useful report identifies what happened, what you expected
and the relevant moment. Share only information you consent to provide. Feedback
is for improving the service and is separate from the interview assessment.

Propose a format using the format issue template, or contribute through
[CONTRIBUTING.md](CONTRIBUTING.md). For vulnerabilities, use the private process
in [SECURITY.md](SECURITY.md). This is a community preview with no guaranteed
support response time or availability commitment.
