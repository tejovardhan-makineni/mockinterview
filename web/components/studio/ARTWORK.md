# Interviewer artwork

The Alex, Jordan and Sam portraits in Avatar3D.tsx are original SVG geometry created for this repository in September 2026. They use no reference photographs, real-person likenesses, third-party character models, textures or external services. They are distributed under the project AGPL-3.0 license. Animation uses the interview audio playback drive and honors reduced motion.

Legacy Ready Player Me binary assets and renderers are no longer used by the application.
